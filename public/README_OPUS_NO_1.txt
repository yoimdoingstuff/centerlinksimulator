=====================================================
CENTRELINK CALL SIMULATOR — HOLD MUSIC DROP-IN FOLDER
=====================================================

To easily play your own MP3 recording of Opus No. 1 (or any hold music):

1. Simply copy or drop your MP3 file into this "public" folder:
   Name it either:
   - opus-no-1.mp3
   OR
   - hold-music.mp3

2. That's it! The game will automatically detect the file at runtime and play
   it in full fidelity through the telephone bandpass filter and volume ducking
   system when you get put on hold!

If no MP3 file is present in this folder, the game automatically falls back to
the built-in procedural Web Audio synthesizer version of "Opus No. 1".
